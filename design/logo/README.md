# SaqBol Shield Logo

A modern softly curved shield enclosing a navy message bubble and an amber alert dot. This replaces the original tumar-pin silhouette to avoid a Wi-Fi/geolocation interpretation.

## Palette
- Sky blue: #2BA8E0
- Deep blue: #1674B6
- Navy: #0B1220
- Amber: #F2A33A

## Files
- `svg/saqbol-icon.svg`: primary coloured, transparent icon, 1024 square viewBox.
- `svg/saqbol-app-icon.svg`: rounded navy app-tile with centred mark.
- `svg/saqbol-logo-horizontal.svg`: outlined Inter SemiBold wordmark in navy for light backgrounds.
- `svg/saqbol-logo-horizontal-white.svg`: same wordmark in white for dark backgrounds.
- `svg/saqbol-icon-mono-navy.svg`: navy one-colour artwork with transparent cutout.
- `svg/saqbol-icon-mono-white.svg`: white one-colour artwork with transparent cutout.
- `png/*-preview-white.png`: CairoSVG exports on a white background.
- `png/*-preview-navy.png`: CairoSVG exports on #0B1220.
- `png/saqbol-icon-transparent.png`: transparent primary mark.

All previews are rendered from SVG in Python. The 16px intended use retains the shield outline, bubble and alert dot; inspect at final device resolution before shipping.
